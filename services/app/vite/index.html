engineerfamily

engineerfamily.net is a personal website run by Siddharth Engineer. It hosts small games and Strelitzia, a self-hosted job search assistant.

Signing in with Google

Every page can be read without signing in. If you sign in with Google, the site uses your name and email address only to show who is signed in and to let invited users open the Strelitzia dashboard.

Strelitzia can save the resumes and cover letters it writes to your own Google Drive, using the drive.file permission, so it only sees files it created. It works with text documents only. It does not create, edit or analyze images, and it does not use Google data to train AI models.
